# Movie Discovery App

> Global cinema discovery, IMDb ratings, and movie trailer exploration platform.

## Overview

A cinematic discovery web application that interfaces with global movie databases to let users search films, read plot synopses, view IMDb ratings, and discover trending releases.

## Key Features

- Instant title search with debounced API queries
- Rich movie cards showing poster art, release year, genre, and user ratings
- Detailed modal view featuring plot summaries and cast details
- Responsive grid layout optimized for film enthusiasts

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, OMDb/TMDb API, Tailwind CSS

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/movie-search-app.git
cd movie-search-app
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
